WELCOME IN

Your easy guide to unlocking your seaside stay

WAKE
THE KEYPAD
Run your palm over the number pad to wake the keypad. The numbers will light up.
ENTER YOUR
ACCESS CODE
Enter the 6-digit access code shared with you, followed by * (Star).
ACCESS
DENIED
If the wrong access code is entered, the lock will beep and say “Access Denied”. Try the correct access code.
ACCESS
GRANTED
If the correct access code is entered, the lock will beep and say “Access Granted”. Press the handle down to unlock and open the door.

If the lock does not respond, wait a few seconds and wake the keypad again.

Please do not share your access code with anyone outside your travelling group.
