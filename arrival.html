WELCOME IN

Your easy guide to unlocking your seaside stay

WAKE
THE KEYPAD
Run your palm over the number pad to wake the keypad. The numbers will light up.
ENTER YOUR
ACCESS CODE
Enter the 6-digit access code shared with you, followed by * (Star).
ACCESS
DENIED
If the wrong access code is entered, the lock will beep and say “Access Denied”. Try the correct access code.
ACCESS
GRANTED
If the correct access code is entered, the lock will beep and say “Access Granted”. Press the handle down to unlock and open the door.
5
ENTER & RELAX

Enter the apartment and allow the door to close behind you.

If the wrong access code is entered continuously multiple times, the alarm will go off. Allow some time between attempts and then enter the access code.

Before you step out, remember to carry the access code or the phone containing the access code. Call your host if there is any problem.
